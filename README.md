# investment-desk

Slack `#investment` 頻道的工作區與自動化腳本存放處。

## 這個 repo 是做什麼的

`#investment` 頻道日常會做的事 — 追蹤標的、整理行情、彙整研究、產生定期回顧 —
凡是需要「跑一段程式」而不是「打一段字」的部分,程式碼都放在這裡。

Slack 上的討論負責決定「要看什麼」,這個 repo 負責把「怎麼看」變成可重複執行的腳本,
讓同樣的分析不必每次重做一遍。

頻道怎麼用(如何 tag Claude、丟圖分析、請它改 code)請看 **[SLACK.md](./SLACK.md)**。

## 預期會放什麼

- **資料抓取**:行情、財報、總經指標等外部資料的取得與快取
- **分析與報表**:把原始資料整理成可讀的摘要、圖表或定期回顧
- **Slack 整合**:將產出推送回 `#investment`,包含排程觸發的定期訊息

## 目前狀態

早期階段。目錄結構會隨著第一批實際腳本進來再定案,現在刻意不預先造空資料夾。

## 使用方式

尚未有可執行的腳本。第一支腳本進來時,這裡會補上安裝與執行說明
(相依套件、需要的 API 金鑰、如何在本機試跑)。

## 注意事項

- **不要把任何憑證 commit 進來**。API 金鑰、Slack token 一律走環境變數或本機
  未追蹤的設定檔,並確保 `.gitignore` 有涵蓋。
- 這裡的內容僅供內部研究與討論參考,不構成任何投資建議。
